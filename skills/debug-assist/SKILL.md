# 错误排查

系统化定位问题根因，不靠猜。

## 步骤

1. **读完整错误**：别只看第一行——堆栈、错误码、上下文都要看。
2. **复现**：用最小步骤复现（能跑就跑，不能跑就推理）。
3. **缩小范围**：二分法——注释/日志/断点，确定哪一步开始出错。
4. **找根因**：不要停在"表面现象"，问"为什么会这样"直到找到源头。
5. **验证修复**：改完能复现原问题的场景要重测。

## 常见根因模式

- 时序/竞态（异步没等、状态未就绪）
- 空值/未定义（边界没处理）
- 类型不符（隐式转换、字符串当数字）
- 编码/路径（中文路径、BOM、分隔符）
- 依赖/版本（API 变了、缺包）
- 环境差异（本地能跑线上不行）

## 输出

```
现象：...
根因：...（为什么会这样）
修复：...（改哪、怎么改）
验证：...（怎么确认修好了）
```

**不确定时明确说"这是猜测，需要验证"**，不要假装确定。
