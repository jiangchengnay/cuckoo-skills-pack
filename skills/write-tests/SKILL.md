# 编写单元测试

为目标代码写测试，**优先覆盖失败路径**。

## 原则

- **真实集成优先**：能真跑就别 mock。只 mock 外部边界（网络、文件系统、时间）。
- **不写"深 mock 测试"**：不断言"mock 被调用了几次"，那测的是实现不是行为。
- **覆盖失败路径**：非法参数、文件不存在、网络失败、边界值（空/0/超大）。
- **一个测试一个断言点**：失败时能一眼看出哪里坏了。

## 步骤

1. 读被测代码，列出**行为清单**（它承诺做什么）。
2. 对每个行为设计：正常用例 + 至少一个失败用例。
3. 确认测试框架（看项目现有测试文件；常见 vitest/jest/pytest）。
4. 遵循项目现有测试风格与目录结构。

## 输出

给出测试文件（完整），并说明：
- 覆盖了哪些行为
- 哪些行为**没能**覆盖（如需要真实环境）

跑一遍测试确认通过再交付。
