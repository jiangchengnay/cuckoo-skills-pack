# 生成文档

为目标代码/项目生成准确、有用的文档。

## 原则

- **先读代码再写**：文档必须与代码一致，不臆造。
- **写"为什么"和"怎么用"**，不重复"做了什么"（代码本身能说明）。
- **有例子**：关键 API 给最小可运行示例。

## 常见类型

1. **函数/类注释**：职责、参数、返回值、异常、副作用。
2. **README**：这是什么、怎么装、怎么用、常见问题。
3. **API 文档**：端点、方法、参数、返回、错误码。
4. **架构说明**：模块职责、依赖方向、数据流。

## 工作方式

1. 用 read/glob 摸清目标（代码结构、公开接口）。
2. 确定文档类型和受众。
3. 按类型生成，遵循项目现有文档风格。
4. 不确定的行为不写，或标注"待确认"。

## 输出

直接给出文档内容（Markdown），并说明覆盖范围。
