# 解释代码

从整体到细节，讲清代码在做什么。

## 结构

1. **一句话概括**：这段代码解决什么问题。
2. **输入 → 处理 → 输出**：数据怎么流动。
3. **关键步骤**：按逻辑分段讲解（用有序列表）。
4. **易忽略的细节**：边界处理、隐式约定、坑。
5. **依赖关系**：调用了哪些外部函数/模块，起什么作用。

## 规则

- 用 read 实际读代码，不猜。
- 面向"第一次看这段代码的人"，但不要啰嗦到解释"什么是变量"。
- 遇到可疑写法（可能是 bug），单独标注"⚠️ 注意"。
- 代码引用用 `file:line` 标注位置。

## 输出

简洁分段，每段有小标题。关键处可引用 1-2 行原文。
